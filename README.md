# StayOn

下拉栏里的屏幕常亮开关。打开后手机不会按原来的时间自动锁屏，关掉后恢复你原来的设置。

Android 8.0 及以上。部分国产系统会忽略应用自己的亮屏锁，所以 StayOn 在开启期间改的是系统自动锁屏时间。

## 功能

- 应用内开关，以及下拉栏快捷设置磁贴「屏幕常亮」
- 开启后显示常驻通知，展开通知可直接关闭
- 只在开启时拉长自动锁屏时间，关闭、进程退出或开机后会改回原来的值
- 未开启时不留在后台

## 使用

1. 安装并打开「屏幕常亮」。
2. 允许**修改系统设置**。没有这项权限，开关不会生效。
3. 打开「保持屏幕常亮」。
4. 可选：点「添加到下拉栏」。没有弹出系统确认时，下拉状态栏，点编辑，把「屏幕常亮」拖上去。
5. 小米、华为、OPPO 等系统建议把电池策略设为无限制，并允许自启动，否则常亮可能被系统清掉。

关闭方式：

- 再点一次应用内开关或下拉栏磁贴
- 展开通知，点「关闭」

卸载前先关掉常亮。否则系统里被拉长的锁屏时间不会随卸载自动恢复。

## 行为说明

| 状态 | 后台 | 自动锁屏 |
| --- | --- | --- |
| 关闭 | 离开应用后进程退出 | 使用你原来的时间 |
| 开启 | 前台服务保持运行，并显示通知 | 暂时拉长到 7 天，并定期写回，避免被系统改掉 |

开启时会记住当前的 `SCREEN_OFF_TIMEOUT`。关闭时写回这个值。7 天是设置项能稳定接受的时长；期间点亮或触摸屏幕会重新计时。

## 构建

需要 JDK 17 和 Android SDK（`compileSdk` 35）。

```bash
# Windows
gradlew.bat :app:assembleDebug

# macOS / Linux
./gradlew :app:assembleDebug
```

调试包在 `app/build/outputs/apk/debug/app-debug.apk`。

用 Android Studio 打开工程目录即可。本机 SDK 路径写在 `local.properties` 的 `sdk.dir`，这个文件不要提交。

## 权限

| 权限 | 用途 |
| --- | --- |
| 修改系统设置 | 读写自动锁屏时间。需要用户单独授权 |
| 通知 | 显示常驻通知和「关闭」按钮 |
| 前台服务 | 开启期间保持进程，用来维持上述状态 |
| 忽略电池优化 | 可选。降低被系统杀掉的概率 |
| 开机完成 | 开机或覆盖安装后，若常亮已不在运行，则恢复原来的锁屏时间 |

## 兼容性

已在小米 15（Android 16 / HyperOS）上验证：应用自己的亮屏锁挡不住系统锁屏时间，改写 `SCREEN_OFF_TIMEOUT` 可以。其他机型如果仍会按时锁屏，把本应用的电池策略设为无限制后再试。

## 项目结构

```text
app/src/main/java/app/stayon/
  MainActivity.kt        开关、权限和磁贴入口
  StayOnService.kt       前台服务，拉长并维持锁屏时间
  StayOnTileService.kt   下拉栏磁贴
  ScreenTimeout.kt       保存并恢复原来的锁屏时间
  IdleExit.kt            未开启时退出进程
```
